# Personagens Skyfall RPG v0.1.8 — modelos de NPC

API opcional para preparar modelos e criar NPCs com o motor do Criador: benefícios,
treinamento, nível, inventário, dinheiro e vida. Integra com QUEDAÇO 0.18.5 sem criar
dependência obrigatória; o Criador continua funcionando sozinho.

A prévia resolve os compêndios antes de criar. Fichas existentes não são substituídas
nem adotadas por nome. Relações entre modelos podem gerar vínculos entre suas fichas.
Uma falha parcial identifica a ficha para revisão e não a apaga nem recria.

Validação: 57 testes automatizados com dados fictícios, empacotamento público e
verificação dos imports do pacote. Ainda é necessária conferência de criação completa
com os compêndios reais no Foundry 13/Skyfall 1.0.1. Nenhum Actor oficial foi criado
durante o desenvolvimento.
