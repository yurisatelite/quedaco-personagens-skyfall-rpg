# 0.1.9 — lotes de NPCs

Prévia e criação em lotes de até 200 personagens usando o motor existente.
API prepareNpcBatch/createNpcBatch, assinaturas, relatório por NPC e relações
após criação. IDs estáveis, conflitos de nome e fichas com pendência são
validados. Equipe, tags, descrição e origem do módulo acompanham o modelo.
Integração com Cadastro QUEDAÇO 0.18.6 e formato de documento QUEDACO-NPCS 1.
Testes com documentos fictícios; comportamento com compêndios reais ainda
precisa de conferência dentro do Foundry 13. Nenhum Actor oficial foi criado.
